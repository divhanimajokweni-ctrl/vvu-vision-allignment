Smart Contract: VVUAnchor.sol

Immutable, append-only anchor on Polygon Amoy. No proxy, no admin keys, no upgrade.

FunctionGas (est.)Description
anchorMerkleRoot()25,000Store Merkle root + emit event
anchorWormHead()30,000Store WORM head + seq + emit event
recordCesiumIOBRender()30,000Record render receipt + emit event
tripCircuitBreaker()25,000Slash anchor below confidence threshold
registerStream()25,000Register new stream + operator

Security Properties

  • No upgradability: No proxy, no implementation slot, no admin key
  • No external calls: Zero external calls. No reentrancy risk.
  • No pause: No circuit breaker in contract. New contract on fix.
  • Operator-only writes: Only registered operator can anchor
  • Append-only: Storage overwritten but every write emits event
  • No token: Contract holds no value. Max loss = gas spent.

Cost

~$0.0001 per anchor on Polygon (vs ~$0.50 on Ethereum). Daily cost for 10 tenants: ~$0.016.
