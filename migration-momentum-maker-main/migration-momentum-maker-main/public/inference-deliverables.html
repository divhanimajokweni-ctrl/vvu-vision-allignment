How to verify in 4 presses

  1. Press ▶ Open Model Registry — the surface loads with the heading "VVU Inference Gateway · Model Registry · WORM Ledger · Epistemic Humility".
  2. Toggle a model ON (e.g. MSFMamba).
  3. Press Run Inference on that card.
  4. A SHA-256-hashed, model-versioned entry appears in the WORM Inference Log with status PROVEN / INCONCLUSIVE / BLOCKED.
