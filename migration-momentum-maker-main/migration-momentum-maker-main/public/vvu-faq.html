General

▶ What is VVU · STUDIO?

VVU · STUDIO is a founder-owned industrial asset-protection platform. It combines 5 environments (Forge, Bench, Fire, Field, Press), an epistemic doctrine that governs how claims become proofs, end-to-end e-commerce, a 5-model AI inference gateway, and an edge-mesh security command center — all under one roof.

It is built on the principle that fire never emits PROVEN: financial actions cannot self-authorize. They must be backed by a proof from the Epistemic Runtime.

Epistemic Doctrine

▶ What is the epistemic doctrine?

A set of rules governing how claims become proofs, and how proofs authorize actions. It is the intellectual core of the platform. The doctrine enforces that observations (from sensors, AI models, or humans) can never directly trigger financial or physical actions — they must first pass through the Epistemic Runtime.

▶ What are the tier tags?

Four tiers, in ascending order of trust:

• RAW — Unverified input (any sensor or user)
• COMPUTED — Derived from RAW via a known function
• VERIFIED — Checked against a second, independent source
• PROVEN — Cryptographically anchored, replayable, epoch-tagged

Only the Epistemic Runtime can emit PROVEN. Fire (financial) and AI models never can.

▶ What is the Oracle Boundary?

The Oracle Boundary is the rule that AI models are Distributed Oracles — they observe, they never assert tier. A model can say "I see a flood with 87% confidence." It cannot say "this is PROVEN." The model's output must pass through the Epistemic Runtime, which may corroborate, reject, or mark it INCONCLUSIVE.

▶ What is the constitutional invariant (Article I §1.3)?

The machine-enforced rule: vote=PASS + proof=FAIL + authorization=EXECUTE → REJECTED.

Even if a vote passes AND the action is authorized, if the underlying proof has not reached the required tier, the action is rejected. This prevents "trust the vote" from overriding "trust the evidence."

▶ What is the Two-Gate Execution Rule?

Every action must pass two independent gates:

1. Epistemic gate — Is the claim verified to the required tier?
2. Constitutional gate — Is the action authorized by the current RuleSet?

Both must pass. If either fails, the action is REJECTED.

▶ What is a Constitutional Epoch?

An epoch is a versioned snapshot of the spec + compiled RuleSet. When you change the constitution, a new epoch is created. Proofs minted under epoch N remain permanently interpretable under epoch N's rules — even after epoch N+1 is live. This makes the system replayable and auditable across time.

▶ What is the WORM Ledger?

Write Once, Read Many. An append-only log of receipted events. Every contribution, every inference, every proof is SHA-256 hashed and appended. The file cannot be edited — only extended. This makes the history tamper-evident and replay-resistant.

The platform's payment escrow layer. It holds funds in escrow, issues SHA-256 receipts, and only releases funds when the epistemic + constitutional gates pass. It is the bridge between money (Fire) and proof (Epistemic Runtime).

▶ What is epistemic humility in the gateway?

If sensors diverge or confidence is low, the system emits INCONCLUSIVE or BLOCKED — it never guesses. Example: if DInSAR satellite says 2.6mm displacement but the IoT strain gauge says 0.1mm, the system triggers INCONCLUSIVE + MANUAL_VERIFICATION_REQUIRED with reason SENSOR_DIVERGENCE.

▶ Where is the Python gateway code?

At opt/vvu/bin/vvu_inference_gateway.py (114 lines). It is the middleware that binds the 5 models to the WORM ledger. The full architecture is documented in the architecture doc.

▶ Can a model emit PROVEN?

No. A model can return status: "PROVEN" meaning "the model's verdict is proven," but that is NOT an Epistemic Runtime tier. The model's output must still pass through the Epistemic Runtime's two-gate check before it can authorize any action. This is the Oracle Boundary.

▶ How do I deploy a change?

Commit locally, push to main. Vercel auto-builds. If the build is BLOCKED (hobby plan concurrency limit), trigger manually via the Vercel Git Push API with forceNew=1. Full steps in How-To §17.

▶ Why do APIs sometimes return 500 on first load?

Vercel serverless uses ephemeral /tmp/vvu.db. On a cold start, the schema is being replayed from prisma/schema.sql (27 tables, 41 statements). The very first request may hit the instance before the schema is ready. Refresh once — the second request hits a warm instance. The definitive fix is Vercel Postgres (persistent, shared across instances).

▶ Why was my GitHub token revoked?

GitHub's secret scanner auto-revokes Personal Access Tokens that appear in screenshots, pastes, or public repos. If you paste a PAT into a chat or upload a screenshot of it, GitHub may detect and revoke it within minutes. Generate a new one at github.com/settings/tokens with repo scope.

▶ How do I add the custom domain?

The domain vvu-control.space-z.ai is already added to the Vercel project. You need to add 2 DNS records at your space-z.ai DNS provider:

1. TXT _vercel.space-z.ai → vc-domain-verify=vvu-control.space-z.ai,0264784c9ef07833e6ed
2. CNAME vvu-control.space-z.ai → cname.vercel-dns.com

Once both records propagate, Vercel auto-verifies and the domain goes live.

The Game

▶ What is Edge of Oblivion?

A deep-space survival RPG with the Edge of Tomorrow mechanic. You start with a rusty hull and no crew, racing against a rogue black hole. When you die, you wake up at the station keeping your scrap and upgrades. Play it →

▶ How do I play?

WASD to thrust, mouse to aim, click to fire. Avoid the black hole's event horizon. Kill drones (5 scrap) and pirates (15 scrap). Rescue survivors to fill your crew. When you die, buy upgrades at Station Omega and reboot the timeline. Full guide in How-To §16.

▶ Is the black hole physics real?

Yes. The black hole exerts gravitational pull using F = G·M/r² (mass = 100,000). Gravity activates within 2000 units. The event horizon is at 150 units — cross it and you're spaghettified (instant death). Your ship has momentum and drag, so you must manage your velocity.

▶ What carries over when I die?

Your scrap (currency) and upgrades (Reinforced Hull, Ion Thrusters, Twin-Link Cannons) persist across timelines. Your crew does NOT persist — you rescue them fresh each run. The timeline counter increments on each death.

▶ What are the upgrades?

• Reinforced Hull (50 scrap) — +50% max integrity
• Ion Thrusters (50 scrap) — +30% thrust acceleration
• Twin-Link Cannons (100 scrap) — fires 2 projectiles per shot
